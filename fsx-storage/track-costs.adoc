= Monitora i costi e ottieni report sulle risorse in NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory offre una vista consolidata dei costi e dell'utilizzo del tuo file system FSx for ONTAP, aiutandoti a gestire i budget e a ottimizzare le risorse in modo efficace. Puoi anche generare report sui costi delle risorse del tuo file system FSx for ONTAP da condividere con le parti interessate.



[[about-this-task]]
== Informazioni su questa attività

Workload Factory tiene traccia dei costi e dell'utilizzo del file system FSx for ONTAP ottenendo i dati di costo da AWS Cost Explorer. Vengono monitorati i seguenti dettagli di costo: tipo di utilizzo, SKU di utilizzo, tipo di deployment, utilizzo e costo totale.

Per le risorse uniche, Workload Factory calcola i costi combinando l'utilizzo effettivo del livello di prestazioni, una quota proporzionale dei costi del livello di prestazioni allocata allo spazio allocato ma non utilizzato, le allocazioni di prestazioni distribuite per capacità e l'utilizzo del pool di capacità. Workload Factory moltiplica ciascun componente per il suo prezzo unitario per quella dimensione e somma i risultati per determinare il costo totale per ciascuna risorsa.

Nella dashboard dei costi, puoi filtrare i dati relativi a costi e utilizzo in base ad account AWS, credenziali, una o più regioni e intervalli di tempo, in modo da comprendere il consumo del tuo file system FSx for ONTAP. Workload Factory mostra sempre i dati su base mensile. Puoi anche filtrare in base a uno o più file system e a uno o più volumi all'interno di un file system. Le chiavi e i valori delle chiavi dei tag di allocazione dei costi AWS aggiungono un ulteriore livello di filtraggio per individuare costi specifici. Un tag è composto da una chiave e un valore. Per filtrare in base alle chiavi dei tag e ai valori delle chiavi dei tag, assegna tag ai tuoi file system FSx for ONTAP. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["Scopri di più sui tag di allocazione dei costi di AWS."^]

Workload Factory ottiene i dati relativi ai costi e all'utilizzo per le risorse del file system FSx for ONTAP da AWS Cost Explorer utilizzando le seguenti autorizzazioni: `ce:GetCostAndUsage` e `ce:GetTags`. Calcoliamo il costo totale utilizzando l'API dei costi di AWS e le nostre stime.

Oltre ai dati sui costi nella dashboard dei costi, il riepilogo esecutivo dei costi mostra i costi del tuo file system FSx for ONTAP e i modelli di spesa della tua organizzazione. Puoi anche generare report sui costi per le risorse del tuo file system FSx for ONTAP. Il report è un file CSV scaricabile che puoi condividere con le parti interessate.



[[track-costs]]
== Tieni traccia dei costi

I costi visualizzati nella console di Workload Factory nella dashboard dei costi si basano sui dati di AWS Cost Explorer, che sono aggiornati ogni 24 ore.

.Prima di iniziare
Verifica che tu soddisfi i seguenti requisiti:

* Devi link:add-credentials.html["Concedi le credenziali con il criterio di autorizzazione _view, planning, and analysis_"^] in Workload Factory per tenere traccia dei costi di FSx per ONTAP.
* Per filtrare in base ai tag di allocazione AWS, verifica che ai tuoi file system FSx for ONTAP siano stati assegnati dei tag.


.Passaggi
. Accedi al link:https://console.netapp.com["NetApp Console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger serve per passare a Workloads, la voce di menu di Workload Factory"], *Carichi di lavoro* > *Archiviazione* > *FSx for ONTAP*.
. Dal menu *FSx for ONTAP*, seleziona *Costo*.
. Dalla dashboard dei costi, filtra i dati relativi a costi e capacità delle tue risorse FSx for ONTAP fornendo le seguenti informazioni:
+
.. *Account AWS*: seleziona gli account per cui vuoi visualizzare i dati sui costi.
.. *Credenziali*: Seleziona le credenziali con autorizzazioni di _visualizzazione, pianificazione e analisi_.
.. *Regioni*: Seleziona le regioni AWS per le quali vuoi visualizzare i dati sui costi.
.. *Intervallo dei dati sui costi*: Seleziona l'intervallo di tempo per cui vuoi visualizzare i dati sui costi.
.. *Chiave tag di allocazione*: (Facoltativo) Seleziona una chiave tag di allocazione e il relativo valore per generare un report dettagliato dei costi per tutti i file system FSx for ONTAP associati al tag AWS.
.. *Valori del tag di allocazione*: (Facoltativo) Seleziona il valore della chiave del tag di allocazione associato alla chiave del tag di allocazione per generare un report dettagliato dei costi per tutti i file system FSx for ONTAP associati al tag AWS.


. Visualizza i *Dettagli sui costi* delle tue risorse FSx for ONTAP.




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== Genera report sui costi per le tue risorse FSx for ONTAP

Genera report sui costi per risorse specifiche del file system FSx for ONTAP da condividere con le parti interessate.

.Passaggi
. Nella dashboard dei costi, seleziona *Genera report*.
. Nella schermata Report, fornisci le seguenti informazioni:
+
.. *File system*: Seleziona uno o più file system FSx for ONTAP da includere nel report.
.. *Volume*: (Facoltativo) Seleziona uno o più volumi da includere nel report.




.Risultato
Viene generato un report in formato CSV che puoi scaricare.
