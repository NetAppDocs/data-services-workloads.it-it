= Elimina un file system in NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per eliminare un file system in NetApp Workload Factory, devi prima eliminare tutti i volumi, le VM di storage o le relazioni di replica associate al file system.

.Passaggi
. Accedi al link:https://console.netapp.com["NetApp Console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger serve per passare a Workloads, la voce di menu di Workload Factory"], *Carichi di lavoro* > *Archiviazione* > *FSx for ONTAP*.
. Da *FSx for ONTAP*, seleziona il menu delle azioni del file system FSx for ONTAP che vuoi eliminare.
. Seleziona *Gestisci*.
. Nella scheda *Panoramica*, seleziona il menu Azioni.
. Seleziona *Delete*.
. Nella finestra di dialogo Elimina file system FSx for ONTAP, inserisci il nome del file system FSx for ONTAP da eliminare.
. Seleziona *Delete* per confermare.
