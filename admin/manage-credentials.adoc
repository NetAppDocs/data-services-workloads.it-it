= Rimuovi le credenziali da NetApp Workload Factory
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Se non hai più bisogno di un set di credenziali, puoi eliminarle da Workload Factory. Puoi eliminare solo le credenziali non associate a un file system FSx for ONTAP.

.Passaggi
. Accedi al link:https://console.netapp.com["NetApp Console"^].
. Dal menu NetApp Console, seleziona *Workloads* > *Administration* > *Credentials*.
. Nella pagina *Credenziali*, procedi come segue:
+
** Nella console di Workload Factory, seleziona il menu delle azioni per un set di credenziali e quindi seleziona *Rimuovi*. Seleziona *Rimuovi* per confermare.
** Nella NetApp Console, seleziona il menu delle azioni per un set di credenziali e quindi seleziona *Delete*. Seleziona *Delete* per confermare.
