= Collega i tuoi file system FSx for ONTAP a VMware Cloud on AWS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo aver distribuito i file system FSx for ONTAP, devi connettere il sistema alla tua infrastruttura VMware Cloud on AWS. Il tuo Software-Defined Data Center (SDDC) offre opzioni di rete per connettersi al file system FSx for ONTAP utilizzando la funzionalità di peering VPC per estendere la connettività di rete ai volumi di storage NFS esterni.

https://aws.amazon.com/blogs/apn/introducing-vpc-peering-for-amazon-fsx-for-netapp-ontap-with-vmware-cloud-on-aws/["Leggi VPC Peering for Amazon FSx for NetApp ONTAP with VMware Cloud on AWS"^]

Il diagramma seguente mostra come utilizzare il peering VPC per connettere cluster SDDC con una singola Availability Zone (AZ) alle implementazioni FSx for ONTAP in una singola AZ.

image:diagram-vpc-connect-vmware-fsx.png["Diagramma che illustra come utilizzare il peering VPC per connettere cluster SDDC single-AZ a implementazioni FSx for ONTAP single-AZ."]
